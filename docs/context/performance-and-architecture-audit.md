# Horizon Performance & Architecture Audit

> Living engineering map generated by multi-model discovery (`gemini-4-hydrogen`) and multi-pass `gemini-4-neon` (Medium) optimization swarms, verified under **Release NativeAOT (`win-x64`)** on both `Horizon.Testing` and `Hex`.

---

## 1. Non-Negotiable Architecture & Hot-Path Invariants

1. **Three Threads** (`CORE.md`, `Horizon/Core/Windowing/WindowManager.cs`):
   - **Platform (Window) Thread**: Owns OS window lifecycle, pumps events (`IPlatformLoop.Run`), runs `PlatformDispatcher` (`Post`/`Invoke`), and owns clipboard/native dialogs.
   - **Render Thread**: Sole owner of Vulkan `GraphicsDevice` and GPU resources (`Initialize`, `Dispose`, `Render`, `EntityLifecycle.Flush`, `Exclusive`). Constructors **never** touch the GPU.
   - **Simulation Thread**: Owns `UpdateState`, `UpdatePhysics`, `Capture`, and **all `Horizon.UI`** (`Measure`, `Arrange`, `Paint`, control state). Parks briefly at `EndTick` via `Rendezvous()` only when `exclusiveRequested || EntityLifecycle.HasWork`.
2. **Snapshot Decoupling**: Render thread reads immutable/double-buffered `Snapshot<T>` slots via `RenderFrame.Active`, never live mutable simulation state.
3. **Zero Hot-Path Allocations & Closures**: `Horizon.Tests/Core/HotPathTests.cs` fails the test suite if any listed per-tick/per-frame method constructs a closure (`NEWOBJ`). No LINQ, boxing, `params`, or string interpolation in per-tick/per-frame loops.
4. **NativeAOT & Boundary Hygiene**: `Horizon.UI` and core `Horizon` maintain zero dynamic reflection (`BoundaryTests.cs` enforces no `Silk.NET` or Vulkan leaks in public/cross-layer signatures). Note: any `.slang` edit requires rebuilding `Horizon/shaders/packed/horizon.hzshaders` via `Horizon.Shaders.Build` (`refresh` + `build`).

## 2. Cross-Subsystem Hot-Path Map & Identified Bottlenecks (Hydrogen Discovery Wave 1)

### 2.1 Core, Physics, Audio & Content (Scout 1)
- **Bugs**:
  - `PhysicsWorld.UpdatePhysics` (`Horizon/Physics/2D/PhysicsWorld.cs:295-431`): double-bounces on simultaneous multi-tile/multi-fixture contact; `BodiesPush == false` overwrites `other.Velocity` (clobbering perpendicular axis); `ActiveContacts` updated asymmetrically.
  - `PhysicsFluidParticleGroup` + `PhysicsCheck` (`Horizon/Physics/2D/Simulation/PhysicsFluidParticleGroup.cs:238,515,607`): thin-wall tunneling & settling issue causing `check-physics` `"and it lies level in its basin"` failures.
  - `PhysicsStaticGrid.Refresh` (`PhysicsStaticGrid.cs:66-78`): compares only fixture count (`_builtFrom`), missing swapped bodies, position moves, or resized fixtures.
  - `CharacterController3D.Slide` (`CharacterController3D.cs:263-290`): step-up fallback overwrites crouch `KeepOnEdge` clamp and walks player off ledges.
  - `AudioMixer` (`AudioMixer.cs:68,230-286`): high-pitch looping `IndexOutOfRangeException` (`Position -= length` instead of `%=`), `MixStream` drops final buffered frame (`at + 1 >= Buffered`), non-volatile `MasterVolume`/`buses`.
  - `SceneManager` (`SceneManager.cs:536,718`): unparented active/stacked/preloaded/retired scenes miss `Dispose()` on engine shutdown; `SetScene(left)` before `Change` leaves `IsLeaving` stuck `true`.
  - `Entity.cs`: post-dispose `AddEntity`/`AddComponent`; missing `try/finally` around `AllocationLog.End`; `TweenContext.Kill` array allocation; `IntervalRunnerSubstep` infinite loop when `TimeInterval <= 0`; `WorkScheduler.Start<T>` returns `default(T)` to deduplicated callers; `WindowManager.Hidden` ignores `dormant` (1 Hz wakeup); native handle leaks on error paths in `LoopTiming`/`ChildProcesses`/`PseudoTerminal`; `Camera`/`Camera3D` 0x0 division `NaN`; `AssetManager.TryCreate(name)` leak on duplicate key; `ConcurrentLogger`/`Logger` dispose issues.
- **Performance**:
  - `PhysicsWorld`: O(N²×F²) dynamic-vs-dynamic scan without aggregate body AABB pre-pass or spatial grid; `OutlineBodies` closure allocation (`HotPathTests` candidate).
  - `AssetManager`: LINQ + closure + `HashSet` allocations on scene teardown (`Release(AssetScope)`, `RemoveUnnamedExcept`, `Remove`).
  - `AudioDevice` + `AudioMixer`: double `lock (gate)` (`Playing` then `Mix`), blocking Vorbis decode under lock, scalar clamp loop.
  - `CollisionWorld3D.Overlaps`: collects all solids before testing boxes; `WaveFile.Is` ASCII byte[] allocations; `GameEngine.HandOverPixels` double full-frame buffer copy; `ContentFiles.Find` string key allocations.
