# The village's art

None of this was painted here. Two packs off itch.io, cut up by `Art/make_village.py`, which also writes the
maps. Run it with the two packs unpacked next to each other to make the sheets again, or on its own to only
rewrite the maps.

## Tiny RPG Town, by Luis Zuno (ansimuz)

https://ansimuz.itch.io/tiny-rpg-town

`town.png` (the town sheet with its three grass tiles stuck on the end and the credit box taken out), `lab.png`
(the second tech lab), `cave.png`, `hero.png` and `npc.png`. CC0, the licence that comes in the pack says so,
no credit asked for, so this is just us saying thanks.

## AxulArt's Basic Top-down Interior, by AxulArt

https://axulart.itch.io/axularts-basic-top-down-interior

`interior.png`, the insides of the houses. Creative Commons Attribution 4.0 (CC BY 4.0), which asks for credit,
so here it is, and in the example's own text. Not changed, only turned from a palette picture into colours.
