hack.ttf is Hack (regular, version 3.003), the TrueType font itself, a monospace font made for code. The engine
turns it into a signed distance field when it's asked for (see DistanceFieldFont), bold and italic are made out of
that the way they are for every font, so the other three faces aren't here. Hex writes its code in it.
